# Ядро NanoMig (Amiga 500) для Karabas Go / Mini / Mini G

[English version](README.md)

Amiga 500 (OCS / ECS) для плат семейства Karabas Go. Это порт
[NanoMig](https://github.com/harbaum/NanoMig) Тилля Харбаума — то есть
[Minimig](https://ru.wikipedia.org/wiki/Minimig) из проекта MiSTer (Minimig-AGA, только чипсет
OCS / ECS) с процессором TG68K — на Xilinx Spartan-6 XC6SLX25 плат Karabas.

| Плата | Файл ядра | Видео | Звук |
|---|---|---|---|
| Karabas Go | `nanomig.kg1` | VGA, 720x576 50 Гц (31 кГц) | I2S ЦАП (PCM5102) |
| Karabas Mini | `nanomig.kg2` | HDMI, 720x576 50 Гц | HDMI, аналоговый выход (сигма-дельта) |
| Karabas Mini G | `nanomig.kg3` | HDMI, 720x576 50 Гц | HDMI, I2S ЦАП |

Файлы ядра лежат в `src/`. В них нет ни Kickstart, ни других защищённых авторским правом данных.

## Что умеет

- **Процессор:** 68000 (TG68K) со скоростью A500.
- **Чипсет:** OCS как в A500 или A1000, либо ECS (пункт OSD Chipset).
- **Память:** Chip RAM от 512 КБ до 2 МБ, Slow RAM (память «trapdoor» по адресу $C00000) от нуля
  до 1,5 МБ, Fast RAM (Zorro II, autoconfig) нет, 2, 4 или 8 МБ. Chip и Slow RAM — в SRAM платы,
  Fast RAM — в её SDRAM.
- **Kickstart:** любой файл ПЗУ Kickstart размером 256 или 512 КБ с SD-карты.
- **Дисководы:** DF0–DF3, образы ADF на SD-карте, чтение и запись.
- **Жёсткие диски:** IDE как в A600 (Gayle): слот CF-карты платы или образы HDF на SD-карте (два
  устройства: master и slave).
- **Часы:** часы с батарейкой, как у A500 с расширением памяти (MSM6242B); их ведут часы платы.
- **Ввод:** USB-клавиатура и мышь, два джойстика (джойстики платы или USB-геймпады).
- **Видео:** PAL или NTSC, через удвоитель строк Minimig (Amber) в 31 кГц.
- **Звук:** стерео Paula с фильтром нижних частот 4,5 кГц, как в A500.
- **Физический дисковод** (только Karabas Go): см. [ниже](#физический-дисковод-karabas-go).

Чего нет: AGA (A1200), 68020 и более быстрых процессоров, турбо-режима дисковода, расширенных ADF /
IPF / SCP, дискет HD, последовательного и параллельного портов.

## Как начать

1. Скопируйте `nanomig.kg1` (Go), `nanomig.kg2` (Mini) или `nanomig.kg3` (Mini G) в корень
   SD-карты платы.
2. Положите ПЗУ Kickstart на SD-карту как `/amiga/kick.rom` (см. [Kickstart](#kickstart)).
3. Положите образы ADF (и HDF) на SD-карту, например в `/amiga`.
4. Выберите Nanomig в меню ядер. Amiga загрузит Kickstart и попросит дискету: откройте OSD
   (**Menu+Esc**) и выберите образ для DF0 (или нажмите **Menu+F1**).

«Menu» — это клавиша Windows на клавиатуре.

## Меню OSD

**Menu+Esc** открывает и закрывает меню (на джойстике: Start+C). Пункты:

| Пункт | Значения | Горячая клавиша |
|---|---|---|
| DF0 ... DF3 | образ ADF дисковода | Menu+F1 ... Menu+F4 |
| HDD0 | Off / CF card / HDF0: что является IDE-устройством 0 (master) | |
| HDF0 | образ HDF IDE-устройства 0 (при HDD0 = HDF0) | Menu+F5 |
| HDF1 | образ HDF IDE-устройства 1 (slave) | Menu+F6 |
| Kickstart | файл ПЗУ Kickstart | |
| Chipset | OCS-A500 / OCS-A1000 / ECS | |
| Chip RAM | 512K / 1M / 1.5M / 2M | |
| Slow RAM | None / 512K / 1M / 1.5M | |
| Fast RAM | None / 2M / 4M / 8M | |
| Video | PAL / NTSC | |
| Reset | сброс Amiga | Ctrl+Alt+Del |

- По умолчанию — A500 с расширением A501: OCS-A500, 512 КБ Chip RAM, 512 КБ Slow RAM, без Fast RAM,
  PAL, HDD0 = CF card.
- Настройки и выбранные образы сохраняются в файле ядра и восстанавливаются при следующем запуске.
- Чипсет и память применяются при следующем сбросе (пункт Reset, Ctrl+Alt+Del или F12).
- В файловом браузере пункта с образом Enter выбирает файл, Esc — назад. **Del** или
  **Backspace** на пункте, либо `[ Eject ]` в начале браузера, извлекают образ. Браузер пустого
  дисковода открывается там, где выбирали образ в последний раз, на следующем файле (диск 2 после
  диска 1).
- **Ctrl+Alt+Backspace** (джойстик: Start+X) перезапускает плату и возвращает в меню ядер.

## Kickstart

Kickstart в комплект не входит: он защищён авторским правом (продаётся, например, в Amiga Forever
от Cloanto). Ядро загружает файл пункта OSD Kickstart, по умолчанию `/amiga/kick.rom`, при старте и
при выборе другого файла; на время загрузки Amiga держится в сбросе.

- Подходят файлы 256 КБ (1.2, 1.3) и 512 КБ (2.0 и новее). Kickstart 256 КБ зеркалируется в
  верхние 256 КБ, как в A500.
- Файл должен быть простым образом ПЗУ, как в микросхеме (big endian): не зашифрованным ПЗУ Amiga
  Forever (которому нужен `rom.key`) и не с переставленными байтами.
- Какой выбрать:
  - **1.3** (34.5, A500): самый совместимый с играми и демками. В нём нет драйвера IDE, значит, нет
    и жёсткого диска.
  - **2.05** (37.350, A600) или **3.1** (40.063, A600): для жёстких дисков и Workbench 2 / 3. В них
    есть `scsi.device` для IDE Gayle. В ПЗУ 3.1 для A500 / A2000 его нет, и жёсткий диск они не
    видят.

## Дискеты

- Образы — файлы ADF по 880 КБ (DD). До четырёх дисководов.
- Образ, выбранный в OSD, — это дискета, вставленная в дисковод; Amiga замечает смену, как с
  настоящим дисководом. Запись идёт в ADF на SD-карте.
- **Число дисководов:** DF0 есть всегда. DF1–DF3 существуют до самого старшего дисковода с образом
  на момент сброса Amiga (Kickstart ищет дисководы только при старте). Чтобы появился DF1, выберите
  для него образ и сделайте сброс. Пустой дисковод занимает Chip RAM, а некоторые игры A500 вообще
  не работают с внешними дисководами, так что для них оставляйте DF1–DF3 пустыми.
- Скорость дисковода — как у настоящего. Секторы идут с SD-карты через микроконтроллер платы.
- Смена дискеты: Menu+F1 ... Menu+F4 сразу открывает браузер дисковода.

## Жёсткие диски

Интерфейс IDE — Gayle от A600. Нужен Kickstart 2.05 или 3.1 (версии для A600, см. выше). Пункт OSD
HDD0 задаёт, что является IDE-устройством 0 (master):

- **CF card:** CF-карта в слоте платы. Доступ к карте прямой (PIO mode 0), данные на ней лежат так
  же, как на A600, поэтому подходит карта, подготовленная в WinUAE или на A600.
- **HDF0:** образ HDF из пункта HDF0.
- **Off:** устройства 0 нет.

Устройство 1 (slave) — образ HDF из пункта HDF1, если он выбран. При HDD0 = CF card это карта плюс
образ.

Образы HDF:
- Нужны образы с RDB (hardfile «full drive» / «RDB»): `scsi.device` монтирует только разделы из
  RDB. Простой hardfile-раздел без RDB не монтируется.
- Геометрия берётся из RDB; без него (пустой образ) — 16 головок и 63 сектора.
- Образ читается и пишется по сектору через микроконтроллер, поэтому он медленнее CF-карты.
- Ядро не ограничивает размер образа, но см. ограничение 4 ГБ ниже.

### Подготовка CF-карты или образа HDF

Самый простой способ работает на любом компьютере: пустая карта или образ, которые размечаются и
форматируются на самой Amiga в HDToolBox (см.
[Установка Workbench](#установка-workbench-31-на-жёсткий-диск)).

- Используйте CF-карту не больше 4 ГБ или держите разделы в первых 4 ГБ: `scsi.device`
  Kickstart 2.05 / 3.1 не работает за пределами 4 ГБ.
- **Пустая CF-карта.** HDToolBox пишет свой RDB поверх таблицы разделов PC, поэтому сначала
  очистите карту:
  - Windows: `diskpart`, `list disk`, `select disk N` (это должна быть CF-карта: проверьте
    размер!), `clean`.
  - Linux: `sudo wipefs -a /dev/sdX` (это должна быть CF-карта: проверьте через `lsblk`!).

  Когда Amiga разметит карту, Windows предложит её отформатировать: не соглашайтесь.
- **Пустой образ HDF**, например на 512 МБ:
  - Linux / macOS: `truncate -s 512M wb31.hdf` (или `dd if=/dev/zero of=wb31.hdf bs=1M count=512`).
  - Windows: `fsutil file createnew wb31.hdf 536870912` или «Create hardfile» в WinUAE.
- **Подготовка на PC:** образ HDF, созданный и установленный в WinUAE или FS-UAE (конфигурация
  A600: 68000, Kickstart 3.1 A600, IDE-диск A600 / Gayle, hardfile в режиме «full drive / RDB»),
  можно скопировать на SD-карту и использовать как HDF0 / HDF1. Такой образ можно и записать на
  CF-карту не меньшего размера: Linux `sudo dd if=wb31.hdf of=/dev/sdX bs=1M conv=fsync`, Windows —
  Win32 Disk Imager (переименуйте файл в `.img`). WinUAE, запущенный от администратора, может и
  напрямую использовать CF-карту в картридере как IDE-диск.

### Установка Workbench 3.1 на жёсткий диск

Нужны Kickstart 3.1 (A600) и ADF Workbench 3.1 (Install, Workbench, Locale, Extras, Fonts, Storage).
Так же ставится 2.05 / Workbench 2.1.

1. OSD: Kickstart = ПЗУ 3.1; HDD0 = CF card (пустая карта в слоте) или HDD0 = HDF0 и пустой HDF в
   HDF0. Fast RAM 2M или больше не помешает. DF0 = Install3.1.adf. Сброс.
2. Amiga загружается с дискеты Install. Откройте диск, папку HDTools, запустите HDToolBox.
3. Диск показан как «Unknown». Change Drive Type, Define New, Read Configuration, OK, OK.
4. Partition Drive: например, DH0 на 200 МБ под систему и DH1 на остальное. Файловая система — Fast
   File System; MaxTransfer 0x1FE00 — безопасное значение для IDE (Advanced Options, Change File
   System). OK, затем Save Changes to Drive, выйдите из HDToolBox.
5. Сброс (OSD). На Workbench с дискеты Install выделите значок DH0:NDOS, меню Icons, Format Disk,
   имя «Workbench», Quick Format, Format. То же для DH1.
6. Откройте папку Install3.1, значок своего языка, Install, следуйте указаниям, установка на DH0:.
   Дискеты, которые она просит, вставляйте через Menu+F1 (Workbench3.1, Locale, Extras, Fonts,
   Storage).
7. Извлеките дискету из DF0 (Menu+F1, `[ Eject ]`) и сделайте сброс: Amiga загрузится с жёсткого
   диска.

Workbench 1.3 на жёсткий диск здесь не установить: в Kickstart 1.3 нет драйвера IDE.

## Физический дисковод (Karabas Go)

На Karabas Go есть 34-контактный разъём дисковода PC / Shugart. Настоящий дисковод на нём может
работать как дисковод Amiga: в браузере DF0 ... DF3 пункты `[ Physical DF0 ]` и `[ Physical DF1 ]`
делают этот DF дисководом на линии выбора 0 или 1 разъёма. **Это в разработке и пока не входит в
релиз.**

- **Physical DF0** — дисковод на DS0 (контакт 10), **Physical DF1** — на DS1 (контакт 12).
  Дисковод PC 3,5" с завода настроен на DS1, поэтому на прямом (не перекрученном) кабеле это
  Physical DF1. Gotek или дисковод Shugart перемычкой ставится на DS0 или DS1. Линия мотора
  (контакт 16) у них общая.
- Используйте дискеты 3,5" DD: Amiga читает и пишет только DD (880 КБ).
- На разъёме нет линии смены дискеты (контакт 34), поэтому ядро её эмулирует. Извлечение дискеты
  замечается, пока дисковод крутится (пропадают индексные импульсы); вставленная дискета —
  когда Amiga её ищет (раз в несколько секунд она шагает головкой, и тогда ядро ненадолго
  включает мотор). Для надёжности после смены дискеты выберите `[ Physical DFn ]` в OSD ещё раз: для
  Amiga это смена дискеты.
- Защищённые от копирования оригиналы читаются как на настоящей Amiga — насколько позволяет
  сепаратор данных ядра (из [MiSTer floppy RobSmithDev](https://mister.robsmithdev.co.uk)).

## Клавиатура

USB-клавиатура работает как клавиатура Amiga. Клавиши, которые отличаются:

| Клавиша PC | Amiga |
|---|---|
| Left Win / Right Win | Left Amiga / Right Amiga |
| Left Alt / Right Alt | Left Alt / Right Alt |
| Left Ctrl | Ctrl (Right Ctrl не используется) |
| End, Insert | Help |
| Page Down | Right Amiga |
| Home / Page Up | цифровой блок ( / ) |
| Delete | Del |
| ` (левее 1) | ` |
| Caps Lock | Caps Lock (с фиксацией, как клавиша Amiga) |
| F1 ... F10 | F1 ... F10 |
| F12 | сброс Amiga, пока клавиша нажата |
| Цифровой блок | цифровой блок |

Клавиши Windows — это ещё и клавиша Menu платы: Menu+Esc, Menu+F1 ... F6 уходят в OSD, а не в
Amiga. Автоповтор — от AmigaOS (сама клавиатура клавиши не повторяет).

Сброс: **F12** (удерживать), **Ctrl+Alt+Del** или пункт OSD Reset.

## Мышь и джойстики

- USB-мышь — в порту 1 Amiga (порт мыши).
- Левый джойстик платы (или первый USB-геймпад) — порт 2 Amiga, джойстиковый порт, который
  используют игры.
- Правый джойстик — порт 1 Amiga, вместе с мышью: порт 1 становится джойстиком при нажатии его
  кнопки огня и снова мышью при нажатии левой кнопки мыши.
- Кнопки: A — огонь, B — вторая кнопка огня, C и Start — кнопки 3 и 4.
- USB-геймпады раскладывает прошивка (`drivers/*.ini` на SD-карте).

## Часы

Amiga видит часы расширения памяти A500 (MSM6242B по адресу $DC0000). Они идут от часов платы с
батарейкой.

- Kickstart 2.0 и новее читает их при загрузке. Установка времени в Prefs / Time (или
  `SetClock SAVE`) устанавливает часы платы.
- В Workbench 1.3 добавьте `SetClock LOAD` в `S:Startup-Sequence`.

## Сборка

Ядро собирается Xilinx ISE 14.7 под Linux: `src/build_go.sh`, `src/build_mini.sh`,
`src/build_minig.sh` (по одному: у них общие рабочие каталоги). Модули платы — submodule `modules/`
([karabas-go-modules](https://github.com/andykarpov/karabas-go-modules)): клонируйте с
`git clone --recursive` или выполните `git submodule update --init`. Для `make_core.py` рядом с этим
репозиторием должен лежать репозиторий
[karabas-go-tools](https://github.com/andykarpov/karabas-go-tools). Симуляции (ISim) — в
`src/sim`. Подробности устройства ядра и тестов — в `CLAUDE.md`.

Прошивка платы с монтированием образов —
[karabas-go-firmware](https://github.com/andykarpov/karabas-go-firmware) (master).
